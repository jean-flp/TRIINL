No TRIINL será possível solicitar o empréstimo de livros de bibliotecas de outras instituições universitárias.
É necessário o uso de ambiente web3. Use ferramentas como Metamask ou um navegador apropriado.

Passo-a-passo para configurar o projeto:
1. Clonar o repositório
2. Na pasta raiz, abrir dois terminais e rodar os seguinte scripts:
 ```
   No primeiro terminal:

   npm i

   npm run install-all #Irá instalar todas as depêndencias.

   npm run app #Irá rodar o aplicativo principal + nó ipfs + backend

   No segundo terminal:

   npm run deploy-contract #Aceite com "y" para ele dar o deploy do contrato na rede
   
 ```
